=== Cégem360 MarketingHub ===
Requires at least: 5.8
Requires PHP: 7.4
Stable tag: 1.0.0
License: MIT

A WordPress-űrlapok beküldéseit továbbítja a Cégem360 MarketingHubba.

== Leírás ==
Támogatott űrlapok: Contact Form 7, WPForms, Elementor Pro, Gravity Forms.

== Telepítés ==
1. Bővítmények → Új hozzáadása → Bővítmény feltöltése: a letöltött zip.
2. Aktiválás.
3. Beállítások → MarketingHub: válaszd ki az űrlapot, és illeszd be a MarketingHub webhook címét
   (MarketingHub → Űrlapok → az űrlap → „Külső űrlap (webhook)”).
4. „Teszt” gombbal ellenőrizd a kapcsolatot.
